## Critical

### C1. Stored XSS: `mapIframe` через `th:utext` без санитайзера

`Index.html:601` рендерит `${current.mapIframe}` через `th:utext`. Сервис `HtmlSanitizerService` существует, но не вызывается перед рендерингом. Любой авторизованный пользователь с доступом к `ContactInfo.mapIframe` (админка) вставляет `<script>` — выполняется у всех посетителей.

- **Файлы:** `src/main/resources/templates/Index.html:601`
- **Фикс:** Заменить `th:utext` на `th:text` ИЛИ вызвать `HtmlSanitizerService.sanitize()` в контроллере перед передачей в модель.

### C2. `login.html` без CSRF-токена — вход не работает

CSRF включён (`.csrf(AbstractHttpConfigurer::enable)`), но форма входа не содержит токена. Все POST на `/login` получают 403 Forbidden.

- **Файлы:** `src/main/resources/templates/login.html`
- **Фикс:** Добавить `<input type="hidden" th:name="${_csrf.parameterName}" th:value="${_csrf.token}"/>` в форму.

### C3. Инвертированная логика уникальности логина/email

`UserServiceImpl.updateUserProfile` проверяет: если логин **не изменился** → «уже существует»; если **изменился** → проверка отсутствует, значение пишется.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/service/impl/UserServiceImpl.java:109-126`
- **Фикс:**
```java
if (!existingUser.getLogin().equals(userDTO.getLogin()) && userRepository.existsByLogin(userDTO.getLogin())) {
    throw new IllegalArgumentException("Пользователь с логином уже существует");
}
existingUser.setLogin(userDTO.getLogin());
// то же для email
```

### C4. Смена логина → 500 после успешного сохранения

После `updateUserProfile` контроллер ищет пользователя по `principal.getName()` (старый логин) → `null` → `modelMapper.map(null, ...)` → `IllegalArgumentException`.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/controller/client/LkController.java:169-172`
- **Фикс:** После сохранения искать по новому логину: `userRepository.findByLogin(userDTO.getLogin()).orElseThrow(...)`.

### C5. `GlobalExceptionHandler` раскрывает внутренн��е детали

`ex.getMessage()` кладётся в модель, `error.html` выводит SQL, пути, стектрейсы. JSON-запросы получают HTML вместо JSON.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/exceptions/GlobalExceptionHandler.java:21-27`
- **Фикс:** Детали — только в лог. Пользователю — нейтральное сообщение. Разделить `@RestControllerAdvice` и MVC.

### C6. NPE в обработчике ошибок `LkController`

`e.getMessage()+": "+e.getCause().getMessage() ==null?"":"")` — операторный приоритет делает условие всегда ложным, `getCause()` может быть `null` → NPE в обработчике.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/controller/client/LkController.java:188`
- **Фикс:** `log.error("Ошибка при обновлении профиля", e); model.addAttribute("error", "Не удалось обновить профиль");`

## High

### H1. Пароль SMTP в открытом виде

`MailSettings.password` хранится plaintext. Форма `th:field="*{password}"` рендерит пароль в `value` атрибуте — виден в DOM, истории браузера.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/model/MailSettings.java:42`, `src/main/resources/templates/fragment-admin.html:3235`
- **Фикс:** Шифровать через `CryptoService`. В форму — пустое поле («оставьте пустым, чтобы не менять»).

### H2. `@ToString` на `User` — пароль в логах

`@ToString` включает `password`. `CRUDController` логирует сущность целиком → пароль в debug-логах.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/model/User.java:17`
- **Фикс:** `@ToString(exclude = "password")`.

### H3. Валидация файлов: только MIME-тип, обходимо

`AbstractCRUDService.validateFile()` проверяет `contentType.startsWith("image/")` — клиентский `null` проходит. `x.html` с `Content-Type: image/png` сохраняется в web-каталог → stored XSS.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/service/impl/AbstractCRUDService.java:200-204`
- **Фикс:** Allowlist расширений + magic bytes (`ImageIO.read()`), безопасное серверное имя, перекодирование картинки.

### H4. Нет `@Transactional` на `saveImg()` / `deleteById()`

Файл пишется до БД (сирота при ошибке) / удаляется до БД (строка без файла при ошибке).

- **Файлы:** `src/main/java/ru/tattoo/maxsim/service/impl/AbstractCRUDService.java:87-99, 156-179`
- **Фикс:** `@Transactional` + `TransactionSynchronizationManager` для удаления файлов после коммита.

### H5. `PriceSectionServiceImpl.create()` — `findById(null).get()`

Форма без `id` → `findById(null)` → `Optional.get()` → `NoSuchElementException` → 500.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/service/impl/PriceSectionServiceImpl.java:44-50`
- **Фикс:** Обрабатывать `id == null` как insert-случай.

### H6. `UserServiceImpl.findByLogin()` — `modelMapper.map(null, ...)`

`userRepository.findByLogin(login).orElse(null)` → `modelMapper.map(null, UserDTO.class)` → `IllegalArgumentException`.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/service/impl/UserServiceImpl.java:96`
- **Фикс:** `userRepository.findByLogin(login).map(u -> modelMapper.map(u, UserDTO.class)).orElse(null)`.

### H7. Swagger/OpenAPI публично

`/swagger-ui/**`, `/v3/api-docs/**` в `permitAll` — полная карта эндпоинтов.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/config/SecurityConfig.java:45-46`
- **Фикс:** Закрыть ADMIN или `springdoc.api-docs.enabled=false` в prod.

### H8. Docker от root

Нет `USER` в Dockerfile → RCE = root в контейнере.

- **Файлы:** `Dockerfile`
- **Фикс:** `RUN adduser --disabled-password --gecos "" appuser` + `USER appuser`.

### H9. `allow-bean-definition-overriding=true`

Маскирует дубли бинов → непредсказуемое поведение.

- **Файлы:** `src/main/resources/application.properties:38`
- **Фикс:** Удалить, исправить причину дублей.

### H10. Дефолтный профиль `dev` — стектрейсы клиенту

`spring.profiles.active=${SPRING_PROFILES_ACTIVE:dev}` + `server.error.include-stacktrace=always` → стектрейсы по умолчанию.

- **Файлы:** `src/main/resources/application.properties:6`
- **Фикс:** Дефолт — `prod`, стектрейсы — только в dev.

### H11. Нет security-заголовков

Только `frameOptions(sameOrigin)`. Нет CSP, HSTS, X-Content-Type-Options, Referrer-Policy, `Secure`/`SameSite` cookie.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/config/SecurityConfig.java:70-74`
- **Фикс:** Добавить заголовки + `server.servlet.session.cookie.secure=true`, `same-site=lax`.

### H12. `ContactController.sendMail()` без `@Valid`

Нет валидации формы — некорректный/вредоносный ввод достигает email-сервиса.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/controller/client/ContactController.java:39`
- **Фикс:** `@Valid @ModelAttribute("details") EmailDetails details, BindingResult bindingResult`.

### H13. 94 `@Autowired` на полях vs конструкторные

Затрудняет тестирование, скрывает зависимости.

- **Файлы:** Все контроллеры и сервис-имплементации
- **Фикс:** Постепенный переход на конструкторную инъекцию.

### H14. `@ToString` на `ReviewsUser` — PII в логах

`@ToString` включает `userName`, `comment`.

- **Файлы:** `src/main/java/ru/tattoo/maxsim/model/ReviewsUser.java:14`
- **Фикс:** `@ToString(exclude = "userName", exclude = "comment")` или убрать.
