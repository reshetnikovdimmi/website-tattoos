# Рефакторинг main.js — разбиение на модули (IIFE)

## Цель
Разделить `main.js` (~1100 строк) на 9 модулей по доменам.

## Структура

```
src/main/resources/static/js/
├── main.js              ← ТОЧКА ВХОДА (~50 строк)
└── modules/
    ├── ui.js            ← UI компоненты (хедер, меню, карусели, фильтры)
    ├── admin.js         ← админ-панель (updateAdminFragment, reinit)
    ├── forms.js         ← формы (submitForm, getFragmentInfo, showModalMessage)
    ├── gallery.js       ← галерея и эскизы (paginations, delete)
    ├── video.js         ← видео карусель и модальное окно
    ├── mail.js          ← почта, верификация, копирование
    ├── backup.js        ← бэкапы Яндекс.Диск
    ├── image.js         ← загрузка изображений, отзывы
    └── carousel.js      ← admin carousel (goToSlide, prev/next)
```

## Паттерн IIFE для каждого модуля

```javascript
(function(window) {
    'use strict';
    
    function myFunction() { ... }
    
    // Экспорт в глобальную область
    window.MyModule = { myFunction };
})(window);
```

## Исправления багов при рефакторинге

| # | Модуль | Исправление |
|---|--------|-------------|
| C1 | `forms.js` | `submitForm`: `event.target.id` → `event.currentTarget.id` |
| C2 | `admin.js` | `updateAdminFragment`: добавить `.fail()` для error handling |
| C3 | `forms.js` | `modals()`: `.off('click').on('click')` вместо `.on('click')` |
| H2 | `mail.js` | `testSmtpConnection`: убрать первый `showModalMessage` |
| H3 | `image.js` | `sendMail`: убрать `$("#preloder").delay()` из catch |
| H4 | `mail.js` | `sendTestEmail`: проверить `response` перед вставкой |
