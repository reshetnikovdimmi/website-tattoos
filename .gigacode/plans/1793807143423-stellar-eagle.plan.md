# План: Полный код-ревью проекта website-tattoos

## Задача
Выполнить полный код-ревью проекта website-tattoos (Spring Boot 3.4.1, Java 17, Spring Security, Thymeleaf, JPA/Hibernate 6, MySQL 8 + Liquibase, Maven).

## Контекст
- В проекте уже есть детальное код-ревью в `docs/code-review.md` (ветка `feature/backup-scripts`)
- На `main` есть 3 новых коммита с изменениями:
  - CSRF токены для toggleFeatured и backup функций
  - Honeypot защита от спама в контактной форме
  - Изменения в JS и шаблонах
- Нужно проверить текущее состояние кода, включая недавние изменения
- Проверить, были ли исправлены критические проблемы из прошлого ревью

## Подзадачи

### 1. Исследовать недавние изменения
- Прочитать diff последних 3 коммитов
- Проверить качество исправлений CSRF, honeypot

### 2. Проверить исправленные из прошлого ревью
- C1: `/user/**` — перенесён на `/admin/user`?
- C2: DTO регистрации без `id`/`role`?
- C3: `/contact/import` только для ADMIN? `th:text` вместо `th:utext`?
- C4: AES-ключ в env?
- C5: Получатель из настроек?
- H1: CSRF включён? Удаления POST/DELETE?
- H3/H4: Инвертированные проверки уникальности?
- H5: Логи prod без SQL?
- H11: Логотип/тарифы фикс?
- H12: Порт MySQL, креды из репозитория?

### 3. Проверить новые/остальные проблемы
- SecurityConfig: полный анализ
- Контроллеры: авторизация, DTO, валидация
- Сервисы: транзакции, бизнес-логика
- Модель: EAGER, ID-стратегии, @ToString
- Хранение файлов: валидация, безопасность
- Тесты: состояние суиты
- Docker/конфиги: безопасность
- CI/CD

### 4. Сформировать итоговый отчёт
- Critical / High / Medium / Low
- Статус исправленных из прошлого ревью
- Новые发现的问题
- План исправлений
