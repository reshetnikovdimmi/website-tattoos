Инструкция по настройке почты
Как настроить почту
1
Выберите почтовый сервис

Для отправки писем используйте любой SMTP-сервис:

Яндекс Почта Mail.ru Gmail Другой SMTP
2
Получите пароль приложения

Для безопасности используйте специальный пароль для приложений:

Яндекс Почта
  1. Перейдите в настройки аккаунта
  2. Выберите раздел «Пароли приложений»
  3. Создайте новый пароль для «Почта»
  4. Скопируйте полученный пароль
Gmail
  1. Включите двухфакторную аутентификацию
  2. Перейдите в «Пароли приложений»
  3. Выберите приложение «Другое»
  4. Скопируйте сгенерированный пароль
Mail.ru
  1. Перейдите в настройки аккаунта
  2. Выберите раздел «Безопасность»
  3. Включите «Пароли для внешних приложений»
  4. Создайте пароль для приложения
3
Заполните настройки SMTP

Используйте данные для вашего почтового сервиса:

Сервис SMTP Хост Порт (SSL) Порт (TLS)
Яндекс smtp.yandex.ru 465 587
Gmail smtp.gmail.com 465 587
Mail.ru smtp.mail.ru 465 587
Яндекс 360 smtp.yandex.ru 465 587
4
Настройте отправителя

Укажите email и имя отправителя, а также адрес для получения сообщений

Email отправителя: noreply@ваш-домен.ru
Имя отправителя: Тату-студия Maxsim
Email получателя: admin@ваш-домен.ru
5
Проверьте настройки

После заполнения всех полей нажмите «Сохранить настройки», а затем отправьте тестовое письмо

Если письмо не отправляется, проверьте пароль приложения и настройки безопасности
