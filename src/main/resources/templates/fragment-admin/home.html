Рекомендуемый размер: 320x180px (16:9)

  1. Зайдите на страницу видео во ВКонтакте
  2. Нажмите на кнопку «Поделиться» (стрелка вправо)
  3. Выберите «Встроить код» или «Embed»
  4. Скопируйте ссылку из атрибута src тега iframe
  5. Вставьте ссылку в поле выше

Пример ссылки:

https://vk.com/video_ext.php?oid=-174808662&id=456239081&hash=b2f7acf9981a0447
  1. Зайдите на страницу видео на YouTube
  2. Нажмите на кнопку «Поделиться» (стрелка вправо)
  3. Выберите «Встроить» или «Embed»
  4. Скопируйте ссылку из атрибута src тега iframe
  5. Вставьте ссылку в поле выше

Пример ссылки:

https://www.youtube.com/embed/dQw4w9WgXcQ
