Редактирование контактов

Как добавить карту

1
Откройте Яндекс.Карты

Перейдите на yandex.ru/maps и найдите нужное место

2
Нажмите «Поделиться»

Найдите кнопку Поделиться на панели инструментов

3
Выберите «Виджет с картой»

В открывшемся окне выберите вкладку Виджет с картой

Здесь можно настроить размер и внешний вид карты
4
Скопируйте HTML-код

Скопируйте весь HTML-код из поля «Виджет с картой» и вставьте его в поле «Код карты (iframe)» выше

<div style="position:relative;overflow:hidden;"><a href="https://yandex.ru/maps/org/infloriya/47725113483/...">Инфлория</a><iframe src="https://yandex.ru/map-widget/v1/..."></iframe></div>
Важно: Вставляйте весь HTML-код целиком, включая теги <div> и <iframe>
Это полноценный виджет, который содержит ссылки на организацию и карту.
Подсказка: Если у вас есть только ссылка вида https://yandex.ru/map-widget/v1/..., её нужно обернуть в тег <iframe> или скопировать готовый код из Яндекс.Карт.
Пример окна «Поделиться»
Ссылка на карту Виджет с картой Виджет с отзывами
HTML-код:
<div style="position:relative;overflow:hidden;"> <a href="...">Инфлория</a> <iframe src="https://yandex.ru/map-widget/v1/..."></iframe> </div>
Предпросмотр карты
Копировать HTML-код
Обратите внимание: Поле «Код карты (iframe)» принимает только полный HTML-код виджета.
Если вы вставите только ссылку, карта не отобразится.

Добавить способ подтверждения

Код можно получить в панели Яндекс.Вебмастер или Google Search Console
DNS-верификация: скопируйте TXT-запись из Google/Yandex и добавьте её в настройки DNS вашего домена у регистратора. Изменения применяются в течение 15 минут — 48 часов.
Не скачивайте файл с Яндекса!
  1. В Яндекс.Вебмастере выберите способ «HTML-файл»
  2. Скопируйте только код из поля Verification: 5d847838cda4738f (выделен жирным на скриншоте)
  3. Вставьте этот код в поле ниже и нажмите «Сохранить»
  4. Сайт сам создаст файл по адресу https://r1-tattoo.ru/yandex_xxxx.html
  5. Вернитесь в Яндекс и нажмите «Подтвердить» — всё сработает
Файл генерируется автоматически, скачивать и загружать ничего не нужно.
Мета-тег: после сохранения тег автоматически появится в <head> главной страницы сайта. Нажмите «Проверить» в панели поисковика.

Как получить код верификации

1
Яндекс: webmaster.yandex.ru → Добавить сайт → Подтвердить права
Google: Search Console → Добавить ресурс → Подтвердить
2
Выберите удобный способ (рекомендуем Мета-тег — он работает мгновенно, без загрузки файлов).
3
Скопируйте предложенный код (например, 1234567890abcdef для мета-тега или имя файла yandex_123.html).
4
Вставьте код в форму выше, сохраните, затем нажмите «Проверить» в панели поисковой системы.

Как получить OAuth-токен Яндекс.Диска

  1. Откройте oauth.yandex.ru
  2. Создайте приложение типа «Для доступа к API»
  3. В правах отметьте: cloud_api:disk.read cloud_api:disk.write
  4. Скопируйте ClientID из настроек приложения
  5. Перейдите по ссылке (замените ВАШ_CLIENT_ID): https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
  6. Скопируйте токен со страницы и вставьте в поле выше
